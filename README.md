## Number Guessing Game (Java)

A professional **Java Console-Based Number Guessing Game** developed using **Core Java** and Object-Oriented Programming (OOP). This project was created as a Java Development internship project and demonstrates Java programming concepts such as classes, objects, loops, exception handling, file handling, collections, and modular design.



##  Features

- Random number generation
- Player name registration
- Three difficulty levels

  * Easy (1–50)
  * Medium (1–100)
  * Hard (1–500)
- Lives/attempt system
- Smart hint system
- Score calculation
- Player statistics
- Achievement system
- Progress bar
- Colorful console output (ANSI Colors)
- Leaderboard
- High score storage
- Multiple rounds
- Lucky round support
- Bonus round support
- Beep sound
- Exception handling
- Modular OOP architecture

## ▶️ How to Run

1. Clone or download the project.
2. Open it in VS Code, IntelliJ IDEA, or Eclipse.
3. Compile all Java files.
4. Run `Main.java`.
5. Enter your name and start playing.

---

## 🎮 Game Rules

1. Choose a difficulty level.
2. Guess the randomly generated number.
3. You have a limited number of attempts.
4. Receive hints after incorrect guesses.
5. Earn more points by guessing in fewer attempts.
6. Unlock achievements as you play.
7. Try to reach the top of the leaderboard.
